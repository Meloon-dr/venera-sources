# Venera 漫画源

这是 Venera-Next 漫画源仓库，入口索引为 [`index.json`](./index.json)。

## 当前源

- TIBIU 漫画：搜索、详情、章节与图片阅读

## 使用

在 Venera-Next 的漫画源管理中添加仓库索引：

```text
https://raw.githubusercontent.com/Meloon-dr/venera-sources/main/index.json
```

本仓库只收录已按 Venera-Next JavaScript API 编写并完成接口抽样验证的源。原始 `All.json` 是 Legado 源集合，不能直接作为 Venera 源导入；未完成重写和验证的旧源不会直接放入仓库。
